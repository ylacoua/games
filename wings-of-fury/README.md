# כנפי הרעם – Wings of Fury 1944

משחק דפדפן בהשראת Wings of Fury הקלאסי (Brøderbund, 1987). אתה טייס בנושאת מטוסים אמריקאית באוקיינוס השקט, ותוקף איים מבוצרים, ספינות ובוסים.

## איך משחקים
פותחים את `index.html` בדפדפן. אין צורך בהתקנה או בשרת.

| מקש | פעולה |
|---|---|
| ↑ ↓ | טיפוס / צלילה |
| ← → | פנייה לכיוון ההפוך באותו גובה (לחיצה בכיוון הטיסה מגבירה מהירות) |
| W / S | מצערת |
| רווח | מקלעים |
| X | הטלת חימוש (פצצה / רקטה / טורפדו) |
| C | פקודה לכנפיים: ליווי ↔ תקיפה |
| Esc | הפסקה · M השתקה |

נחיתה: מתקרבים לנושאת נמוך, במצערת נמוכה ובאף כמעט ישר. הגלגלים יורדים אוטומטית.

## מה יש במשחק
- 5 מטוסים: הלקט, קורסייר, דונטלס, אוונג'ר, בירקט. לכל אחד צליל מנוע משלו
- חנות שדרוגים: מנוע, שריון, מקלעים, מתלי חימוש, דלק
- עד 3 מטוסי כנף בשליטת המחשב (ליווי או תקיפה)
- 6 משימות עם 3 בוסים: אוניית מערכה, הסירה המעופפת "אמילי", מבצר החוף
- מזג אוויר: יום, שחר, שקיעה, לילה עם זרקורים, גשם, סערה ורוח
- טיסה בגובה רב עם זום אאוט, פנייה בתלת־ממד
- 5 מטוסים לכל משימה והחלפת סוג מטוס על הנושאת
- משימת אימון שבה הכול פתוח וחינמי
- מנגינת 8 ביט בתפריטים

## מבנה הקבצים
| קובץ | תפקיד |
|---|---|
| `js/data.js` | מטוסים, חימוש, שדרוגים, משימות |
| `js/audio.js` | אפקטים, צלילי מנוע ומוזיקה (WebAudio) |
| `js/world.js` | בניית שלב, פני השטח ומצב המשחק |
| `js/entities.js` | מודל הטיסה, נשק, פיצוצים ונזק |
| `js/ai.js` | נ"מ, ספינות, חיילים, מטוסי אויב, בוסים וכנפיים |
| `js/carrier.js` | נושאת המטוסים ותותחי הנ"מ שלה |
| `js/aircraft.js` | ציור כל סוגי המטוסים לפי הפרופיל האמיתי שלהם |
| `js/plane3d.js` | מודל תלת־ממדי למטוס בזמן פנייה |
| `js/render.js` | ציור העולם והתאורה |
| `js/ui.js` | תפריטים ו-HUD |
| `js/main.js` | אתחול, קלט ולולאת המשחק |
